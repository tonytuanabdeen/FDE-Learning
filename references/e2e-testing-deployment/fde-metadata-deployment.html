Ship metadata, not surprises

Salesforce metadata deployment for new forward deployed engineers. Pick a level, then work through each module together.

    Keys: left and right arrows move between modules, 1 2 3 switch level, N toggles speaker notes, P toggles presenter mode. Sample names, IDs and emails are placeholders. Check current Salesforce docs for limits and API versions.

    Deployment cheat sheet

    # auth
sf org login web --alias dev-sandbox
sf org list

# pull from an org
sf project retrieve start --manifest manifest/package.xml --target-org dev-sandbox

# check only (no changes saved)
sf project deploy start --manifest manifest/package.xml --target-org uat --dry-run --test-level RunLocalTests
sf project deploy validate --manifest manifest/package.xml --target-org prod --test-level RunLocalTests

# real deploy
sf project deploy start --manifest manifest/package.xml --target-org uat --test-level RunLocalTests
sf project deploy start --source-dir force-app --target-org dev-sandbox

# after validation passes (production, within 10 days)
sf project deploy quick --job-id 0AfXXXXXXXXXXXX --target-org prod

# status
sf project deploy report --use-most-recent
sf project deploy cancel --use-most-recent

# deletions
sf project deploy start --manifest manifest/package.xml --post-destructive-changes manifest/destructiveChangesPost.xml --target-org uat

# build a manifest from source
sf project generate manifest --source-dir force-app --name manifest/package.xml
