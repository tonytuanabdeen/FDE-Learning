## About this project

This repository contains a **self-contained, GitHub-friendly SVG profile card**
(`profile-card.svg`) with:

- 🪟 **Terminal glassmorphism** — a frosted macOS-style window with ambient
  cyan/magenta radial glows.
- 🌗 **Dual theme** — automatic dark/light switching via
  `@media (prefers-color-scheme)`.
- ⌨️ **Typing effect** — the header types itself in with a blinking cursor.
- ✨ **Animated ASCII art** — a pulsing neon-blue avatar in the left panel.
- ♿ **Reduced-motion aware** — all animation is disabled under
  `prefers-reduced-motion: reduce`.

Everything is pure SVG + inline CSS — no external fonts, scripts, or build step —
so it renders correctly through GitHub's Camo caching proxy.

### Reusing it

Drop the SVG into any GitHub profile `README.md`:

```md
<img src="./profile-card.svg" alt="Your profile card" width="100%" />
```

Then edit the text, pill tags, and ASCII block directly in `profile-card.svg`.
